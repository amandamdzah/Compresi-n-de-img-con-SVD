# Guía para ejecutarlo en vs code (`svd_env`)

## 1. Crear el entorno virtual (Solo la primera vez)
Si estás clonando el repositorio en otra computadora o necesitas recrear el entorno desde cero, abre la terminal en la carpeta raíz del proyecto y ejecuta:

```bash
python -m venv svd_env

**Activar el entorno en Windows (VS Code Terminal / PowerShell):**
```powershell
.\svd_env\Scripts\activate

**En Mac o linux
source svd_env/bin/activate

**Para salir del entorno
deactivate
